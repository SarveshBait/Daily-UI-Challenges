# Modern Calculator UI

A sleek and modern calculator application built using HTML, CSS, and JavaScript with a premium dark-themed glassmorphism UI design.

## 🚀 Features

* Modern dark UI
* Orange & blue glowing effects
* Responsive layout
* Smooth hover animations
* Interactive calculator buttons
* Clean and minimal interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎨 UI Highlights
* Neon glowing border effects
* Hover animations
* Modern typography

```bash
└── assets
```
